## createAnnotatedImage 方法說明

這個方法會在原始影像上繪製測量標註：

```swift
private func createAnnotatedImage(from record: MeasurementRecord) -> UIImage {
    let renderer = UIGraphicsImageRenderer(size: record.image.size)

    return renderer.image { context in
        // 1. 繪製原始影像
        record.image.draw(at: .zero)

        // 2. 設定繪圖樣式
        let ctx = context.cgContext
        ctx.setStrokeColor(UIColor.systemGreen.cgColor)  // 綠色邊框
        ctx.setLineWidth(3.0)                            // 線條寬度

        // 3. 為每個檢測到的物體繪製標註
        for object in record.detectedObjects {
            // 繪製邊界框
            ctx.stroke(object.boundingBox)

            // 繪製尺寸標籤
            if let dimensions = object.dimensions {
                let text = dimensions.formattedDimensions()
                let attributes: [NSAttributedString.Key: Any] = [
                    .font: UIFont.systemFont(ofSize: 24, weight: .bold),
                    .foregroundColor: UIColor.white,
                    .strokeColor: UIColor.black,
                    .strokeWidth: -3.0
                ]

                let textRect = CGRect(
                    x: object.boundingBox.minX,
                    y: object.boundingBox.minY - 30,
                    width: object.boundingBox.width,
                    height: 30
                )

                text.draw(in: textRect, withAttributes: attributes)
            }
        }
    }
}
```

## 標註內容說明

### 1. 邊界框

- **顏色**: 綠色 (systemGreen)
- **線條寬度**: 3.0 點
- **位置**: 圍繞檢測到的物體

### 2. 測量數值

- **字體**: 系統粗體，24 點
- **顏色**: 白色文字，黑色描邊
- **位置**: 邊界框上方
- **內容**: 格式化的尺寸資訊
  - 例如：「15.5cm × 8.2cm × 3.0cm」

### 3. 文字樣式

- **描邊效果**: 黑色描邊讓白色文字在任何背景上都清晰可見
- **描邊寬度**: -3.0（負值表示填充 + 描邊）

## 為什麼會有這個問題？

這是在實作第一階段時的一個小疏漏：

1. **分享功能**實作時正確使用了 `createAnnotatedImage`
2. **儲存功能**實作時直接使用了原始影像 `record.image`
3. 兩個功能應該使用相同的邏輯

這種不一致性在測試時很容易被發現，感謝您的細心測試！

```swift
let renderer = UIGraphicsImageRenderer(size: record.image.size)

    // 繪圖操作
```

- 自動處理不同的色彩空間

- 效能優化
- 記憶體管理自動化

### 文字描邊效果

```swift
.strokeColor: UIColor.black,
.strokeWidth: -3.0  // 負值 = 填充 + 描邊
```

**效果**：

- 白色文字在任何背景上都清晰可見
- 黑色描邊提供對比度
- 專業的視覺效果
