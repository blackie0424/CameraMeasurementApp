# AR 平面偵測準確性 - 快速測試檢查清單

這是一份簡化的測試檢查清單，用於快速驗證核心功能。完整測試請參考 `MANUAL_TESTING_GUIDE.md`。

## 測試前準備 ✓

- [ ] 裝置支援 ARKit（A9 處理器或更新）
- [ ] iOS 12.0 或更新版本
- [ ] 相機權限已授予
- [ ] 準備捲尺或直尺
- [ ] 光線充足的環境
- [ ] 有紋理的測試表面

---

## 快速功能測試（10 分鐘）

### 1. 平面偵測 ✓

- [ ] 啟動應用程式，顯示「正在偵測平面...」
- [ ] 掃描桌面，出現藍色半透明網格
- [ ] 掃描牆面，出現綠色半透明網格
- [ ] 偵測到 2 個平面後，測量按鈕啟用
- [ ] 進度顯示「已偵測 X 個平面」

**預期時間**：30-60 秒完成平面偵測

---

### 2. 測量準確性 ✓

- [ ] 點擊「開始測量」進入測量模式
- [ ] 游標對準平面時顯示綠色
- [ ] 游標未對準平面時顯示紅色
- [ ] 測量 30cm 距離，誤差 < 2%
- [ ] 改變相機角度，測量線不飄移

**測試記錄**：

- 實際距離：30.0 cm
- 測量距離：**\_** cm
- 誤差：**\_** %
- 通過：☐ 是 ☐ 否

---

### 3. 視覺回饋 ✓

- [ ] 游標顏色變化清晰（綠色/紅色）
- [ ] 測量點標記清晰可見（黃色圓點）
- [ ] 測量線條連接兩點
- [ ] 距離標籤易於閱讀
- [ ] 平面視覺化透明度適中

---

### 4. 追蹤品質 ✓

- [ ] 快速移動裝置，顯示警告訊息
- [ ] 平面變為黃色
- [ ] 測量功能被禁用
- [ ] 放慢移動，警告消失
- [ ] 平面恢復原本顏色

---

### 5. 狀態轉換 ✓

- [ ] 點擊「開始測量」進入測量模式
- [ ] 顯示「重新偵測平面」按鈕
- [ ] 點擊「重新偵測平面」回到偵測階段
- [ ] 清除所有測量和平面視覺化

---

## 核心驗收標準

### 必須通過（P0）

- [ ] 能夠偵測平面並顯示視覺化
- [ ] 測量誤差 < 2%
- [ ] 測量線不飄移
- [ ] 游標顏色回饋正常
- [ ] 追蹤品質警告正常

### 應該通過（P1）

- [ ] 平面偵測時間 < 60 秒
- [ ] 跨平面測量正確
- [ ] 重複測量一致性良好
- [ ] 提示訊息清晰
- [ ] 視覺效果流暢

---

## 快速問題排查

### 問題：無法偵測平面

**解決**：改善光線、選擇有紋理的表面、放慢移動速度

### 問題：測量不準確

**解決**：確保游標為綠色時才點擊、等待追蹤穩定

### 問題：測量線飄移

**解決**：檢查是否使用 AnchoredMeasurementPoint、確認平面錨定

### 問題：相機黑屏

**解決**：檢查相機權限、重新啟動應用程式
