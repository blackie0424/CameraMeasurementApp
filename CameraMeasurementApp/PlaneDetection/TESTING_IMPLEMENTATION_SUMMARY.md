# Task 13 實作總結：手動測試與調整

## 概述

本文件總結 Task 13「手動測試與調整」的實作內容。此任務專注於建立完整的手動測試流程和文件，用於驗證 AR 平面偵測與測量準確性功能。

## 實作內容

### 1. 完整測試指南（MANUAL_TESTING_GUIDE.md）

建立了一份詳盡的手動測試指南，涵蓋三個主要測試領域：

#### 測試 1：平面偵測流程測試

**需求覆蓋**：需求 1, 2, 7  
**測試項目**：

- 1.1 初始啟動測試
- 1.2 平面偵測與視覺化測試
- 1.3 測量啟用條件測試
- 1.4 狀態轉換測試
- 1.5 平面移除測試

**驗證內容**：

- AR Session 啟動和平面偵測模式
- 平面視覺化（藍色水平、綠色垂直）
- 測量啟用條件（≥2 平面或面積 ≥0.5m²）
- 狀態轉換（偵測 → 準備 → 測量模式）
- 平面移除動畫（2 秒淡出）

#### 測試 2：測量準確性測試

**需求覆蓋**：需求 4, 6  
**測試項目**：

- 2.1 基本距離測量準確性測試
- 2.2 相機角度改變時的穩定性測試
- 2.3 跨平面測量測試
- 2.4 極端距離測試
- 2.5 重複測量一致性測試
- 2.6 動態環境穩定性測試

**驗證內容**：

- 測量誤差 < 2%（目標準確度）
- 相機角度改變時測量線不飄移
- 跨平面 3D 距離計算正確
- 不同距離範圍的準確性（5cm - 3m）
- 重複測量的一致性（標準差 < 0.5cm）
- 環境變化下的穩定性

#### 測試 3：使用者體驗測試

**需求覆蓋**：需求 3, 5  
**測試項目**：

- 3.1 游標顏色回饋測試
- 3.2 測量點放置回饋測試
- 3.3 追蹤品質警告測試
- 3.4 提示訊息顯示測試
- 3.5 視覺效果和動畫測試
- 3.6 整體使用者體驗評估

**驗證內容**：

- 游標顏色回饋（綠色對準平面、紅色未對準）
- 測量點放置的視覺和觸覺回饋
- 追蹤品質監控和警告顯示
- 各階段提示訊息的清晰度
- 視覺效果品質和動畫流暢度
- 整體易用性和使用者滿意度

## 測試流程

### 完整測試流程（45-65 分鐘）

1. **測試前準備**（5 分鐘）

   - 檢查硬體和環境條件
   - 準備測量工具
   - 確認權限和設定

2. **測試 1：平面偵測流程**（10-15 分鐘）

   - 驗證平面偵測和視覺化
   - 測試啟用條件和狀態轉換

3. **測試 2：測量準確性**（20-30 分鐘）

   - 基本距離測量
   - 穩定性測試
   - 跨平面測量
   - 一致性測試

4. **測試 3：使用者體驗**（15-20 分鐘）

   - 視覺回饋測試
   - 追蹤品質警告
   - 整體 UX 評估

5. **測試報告**（5 分鐘）
   - 整理測試結果
   - 記錄問題
   - 生成報告

### 快速測試流程（10 分鐘）

使用 `QUICK_TEST_CHECKLIST.md` 進行快速驗證：

1. 平面偵測（2 分鐘）
2. 測量準確性（3 分鐘）
3. 視覺回饋（2 分鐘）
4. 追蹤品質（2 分鐘）
5. 狀態轉換（1 分鐘）

## 品質標準

### 核心驗收標準（必須通過）

1. **平面偵測**

   - 能夠偵測水平和垂直平面
   - 平面視覺化正確顯示
   - 啟用條件正確觸發

2. **測量準確性**

   - 測量誤差 < 2%
   - 測量線不飄移
   - 跨平面測量正確

3. **使用者體驗**
   - 游標顏色回饋清晰
   - 追蹤品質警告正常
   - 提示訊息有用

### 品質等級

**優秀**：

- 測量誤差 < 1%
- 重複測量標準差 < 0.3cm
- 使用者滿意度 ≥ 4.5/5

**良好**：

- 測量誤差 1-2%
- 重複測量標準差 < 0.5cm
- 使用者滿意度 ≥ 4.0/5

**可接受**：

- 測量誤差 2-3%
- 重複測量標準差 < 1cm
- 使用者滿意度 ≥ 3.5/5

**不合格**：

- 測量誤差 > 3%
- 重複測量標準差 ≥ 1cm
- 使用者滿意度 < 3.5/5

## 問題管理

### 問題優先級

**P0（嚴重）**：

- 應用程式崩潰
- 核心功能無法使用
- 測量誤差 > 5%
- 必須立即修正

**P1（重要）**：

- 功能異常但有替代方案
- 測量誤差 3-5%
- 使用者體驗問題
- 應該盡快修正

**P2（次要）**：

- 視覺效果問題
- 提示訊息不清晰
- 效能優化
- 可以延後修正

## 測試最佳實踐

### 測試技巧

1. **平面偵測**

   - 緩慢移動裝置
   - 保持 30-50cm 距離
   - 使用 S 形掃描路徑

2. **測量**

   - 等待游標變綠色
   - 保持裝置穩定
   - 確保測量點在視野中

3. **問題重現**
   - 記錄詳細步驟
   - 記錄環境條件
   - 截圖或錄影

### 環境建議

**理想環境**：

- 光線充足（500-1000 lux）
- 有紋理的表面
- 穩定的環境
- 溫度適中

**避免環境**：

- 過暗或過亮
- 純色表面
- 反光表面
- 移動的環境
