# AR 平面偵測準確性 - 手動測試指南

本文件提供完整的手動測試流程，用於驗證 AR 平面偵測與測量準確性功能。

## 測試環境準備

### 硬體需求

- iPhone 或 iPad（支援 ARKit，A9 處理器或更新）
- iOS 12.0 或更新版本
- 實體測量工具：
  - 捲尺或直尺（至少 1 公尺）
  - 已知尺寸的物體（例如：A4 紙 = 21cm x 29.7cm）
  - 平坦的測試表面（桌面、地板、牆壁）

### 環境條件

- **光線充足**：避免過暗或過亮的環境
- **特徵豐富**：表面應有紋理或圖案（避免純白或純黑表面）
- **穩定環境**：避免移動的物體或人員
- **空間充足**：至少 2 平方公尺的測試區域

### 測試前檢查清單

- [ ] 確認相機權限已授予
- [ ] 確認裝置支援 ARKit
- [ ] 清潔相機鏡頭
- [ ] 確保裝置電量充足（建議 > 50%）
- [ ] 準備好測量工具和記錄表格

## 附錄：故障排除指南

### 問題：平面無法偵測

**可能原因**：

1. 光線不足
2. 表面缺乏紋理（純色表面）
3. 移動過快
4. 相機鏡頭髒污

**解決方案**：

- 移動到光線充足的環境
- 選擇有紋理或圖案的表面
- 放慢移動速度
- 清潔相機鏡頭

### 問題：平面視覺化閃爍或不穩定

**可能原因**：

1. 追蹤品質不佳
2. 環境特徵點不足
3. 移動過快

**解決方案**：

- 放慢移動速度
- 移動到特徵豐富的環境
- 確保光線充足

### 問題：測量按鈕無法啟用

**可能原因**：

1. 偵測到的平面數量不足（< 2）
2. 單一平面面積不足（< 0.5m²）
3. 平面偵測品質不佳

**解決方案**：

- 繼續掃描環境，偵測更多平面
- 擴大單一平面的偵測範圍
- 改善環境條件（光線、紋理）

### 問題：應用程式崩潰或無回應

**可能原因**：

1. 裝置不支援 ARKit
2. 記憶體不足
3. iOS 版本過舊

**解決方案**：

- 確認裝置支援 ARKit（A9 處理器或更新）
- 關閉其他應用程式釋放記憶體
- 更新 iOS 到最新版本
- 重新啟動裝置

## 測試 2：測量準確性測試

**目標**：驗證測量功能的準確度和穩定性  
**需求覆蓋**：需求 4, 6

### 2.1 基本距離測量準確性測試

**測試準備**：

- 準備已知長度的物體或使用捲尺標記固定距離
- 建議測試距離：10cm, 20cm, 30cm, 50cm, 100cm
- 記錄實際距離和測量結果

**測試步驟**：

1. 完成平面偵測並進入測量模式
2. 在水平平面上放置已知長度的物體（例如 A4 紙長邊 = 29.7cm）
3. 點擊測量按鈕，將游標對準物體一端
4. 確認游標為綠色（對準平面）後點擊記錄起點
5. 移動裝置，將游標對準物體另一端
6. 確認游標為綠色後點擊記錄終點
7. 記錄顯示的測量結果
8. 計算誤差百分比：|測量值 - 實際值| / 實際值 × 100%

**預期結果**：

- [ ] 測量值與實際值的誤差 < 2%
- [ ] 距離顯示格式為「XX.X cm」（一位小數）

- [ ] 距離標籤顯示在測量線中點

### 2.3 跨平面測量測試

**測試目標**：驗證在不同平面上的測量點能正確計算 3D 距離

**測試場景 A：水平到垂直平面**

**測試步驟**：

1. 偵測一個水平平面（桌面）和一個垂直平面（牆壁）
2. 在桌面上放置起點
3. 在牆壁上放置終點
4. 記錄測量結果
5. 使用捲尺驗證實際 3D 距離

**測試場景 B：兩個不同高度的水平平面**

**測試步驟**：

1. 偵測兩個不同高度的水平平面（例如地板和桌面）
2. 在較低平面上放置起點
3. 在較高平面上放置終點
4. 記錄測量結果
5. 驗證實際距離

**預期結果**：

- [ ] 能夠在不同平面上放置測量點
- [ ] 計算的距離為真實 3D 空間距離（非投影距離）
- [ ] 測量誤差 < 2%
- [ ] 測量線條正確連接兩個平面上的點

**測試記錄**：
| 測試場景 | 平面類型 | 實際距離 (cm) | 測量距離 (cm) | 誤差率 (%) | 通過 ☐ |
|---------|---------|--------------|--------------|-----------|--------|
| 場景 A | 水平 → 垂直 | | | | |
| 場景 B | 水平 → 水平 | | | | |

**驗收標準**：
✅ 需求 6.4：測量點位於不同平面上時，計算跨平面的真實 3D 距離  
✅ 需求 4.5：確保測量線的兩個端點都錨定在穩定的平面上

**3D 距離驗證方法**：
對於跨平面測量，使用畢氏定理驗證：

- 測量水平距離：d_h
- 測量垂直距離：d_v
- 計算理論 3D 距離：d_3d = √(d_h² + d_v²)
- 比較應用程式測量值與理論值

## 附錄：測量準確性問題排查

### 問題：測量值明顯不準確（誤差 > 5%）

**可能原因**：

1. 平面偵測品質不佳
2. 測量點未正確錨定在平面上
3. 追蹤品質不穩定
4. 距離計算公式錯誤

**排查步驟**：

1. 確認游標為綠色（對準平面）時才放置測量點
2. 確認平面視覺化清晰且穩定
3. 檢查追蹤品質是否為 normal
4. 重新偵測平面並重試測量

### 問題：測量線條飄移

**可能原因**：

1. 測量點未錨定到平面錨點
2. 平面錨點更新時測量點未跟隨
3. 使用了 hit test 結果而非平面座標系統

**排查步驟**：

1. 檢查程式碼確認使用 AnchoredMeasurementPoint
2. 確認 worldPosition() 使用 planeAnchor.transform 計算
3. 驗證平面更新時測量點正確跟隨

### 問題：跨平面測量失敗

**可能原因**：

1. 兩個平面未正確偵測
2. 距離計算未考慮 3D 空間
3. 測量點錨定失敗

**排查步驟**：

1. 確認兩個平面都有清晰的視覺化
2. 確認使用歐幾里得距離公式（3D）
3. 檢查兩個測量點都成功錨定

### 問題：測量結果不一致

**可能原因**：

1. 追蹤品質波動
2. 平面偵測不穩定
3. 環境光線變化

**排查步驟**：

1. 改善環境條件（光線、紋理）
2. 等待追蹤品質穩定後再測量
3. 避免快速移動裝置

## 附錄：測試最佳實踐

### 測試環境建議

**理想測試環境**：

- 光線充足的室內環境
- 有紋理的表面（木質桌面、地毯、有圖案的牆面）
- 穩定的環境（無移動物體）
- 溫度適中（避免過熱影響裝置效能）

**避免的環境**：

- 過暗或過亮的環境
- 純色表面（白牆、黑色桌面）
- 反光表面（玻璃、鏡子）
- 移動的環境（車內、電梯）

### 測試技巧

**平面偵測技巧**：

1. 緩慢移動裝置，保持穩定
2. 保持裝置與表面約 30-50cm 距離
3. 以 S 形或 Z 形路徑掃描表面
4. 確保表面在視野中心

**測量技巧**：

1. 等待游標變綠色再點擊
2. 保持裝置穩定，避免抖動
3. 測量時保持適當距離（30-100cm）
4. 確保兩個測量點都在視野中

**問題重現技巧**：

1. 記錄詳細的重現步驟
2. 記錄環境條件
3. 截圖或錄影記錄問題
4. 記錄裝置和系統資訊
