# 使用者偏好儲存系統說明

## 概述

本文件說明相機測量應用程式的使用者偏好儲存系統實作，包含 UserDefaults 整合、設定同步機制和重置功能。

## 架構

### 1. SettingsManager (設定管理器)

`SettingsManager` 是一個單例類別，負責集中管理所有使用者偏好設定。

**主要功能：**

- 集中式設定存取
- 自動同步機制
- 通知系統整合
- 匯入/匯出設定
- 重置功能

**使用方式：**

```swift
let settingsManager = SettingsManager.shared

// 讀取設定
let unit = settingsManager.measurementUnit
let shouldShowGuidance = settingsManager.shouldShowGuidance

// 修改設定（自動同步和發送通知）
settingsManager.measurementUnit = .inches
settingsManager.shouldAutoSave = true
```

### 2. UserDefaults Extension

擴展 `UserDefaults` 提供類型安全的屬性存取。

**支援的設定項目：**

| 設定項目                  | 類型              | 預設值         | 說明                  |
| ------------------------- | ----------------- | -------------- | --------------------- |
| `measurementUnit`         | `MeasurementUnit` | `.centimeters` | 測量單位（公分/英吋） |
| `defaultReferenceIndex`   | `Int`             | `0`            | 預設參考物件索引      |
| `shouldShowGuidance`      | `Bool`            | `true`         | 是否顯示操作引導      |
| `shouldAutoSave`          | `Bool`            | `false`        | 是否自動儲存測量結果  |
| `showConfidenceIndicator` | `Bool`            | `true`         | 是否顯示信心度指標    |
| `enableHapticFeedback`    | `Bool`            | `true`         | 是否啟用觸覺回饋      |
| `saveLocation`            | `Bool`            | `false`        | 是否儲存位置資訊      |
| `hasLaunchedBefore`       | `Bool`            | `false`        | 是否曾經啟動過        |
| `hasSeenInitialGuidance`  | `Bool`            | `false`        | 是否已看過初始教學    |

### 3. 測量單位 (MeasurementUnit)

```swift
enum MeasurementUnit: Int {
    case centimeters = 0
    case inches = 1

    var symbol: String { ... }
    var name: String { ... }
    func convert(_ value: Float) -> Float { ... }
}
```

**功能：**

- 提供單位符號（cm / inch）
- 提供單位名稱（公分 / 英吋）
- 提供單位轉換功能

## 同步機制

### 通知系統

系統使用 `NotificationCenter` 實現設定變更的即時同步：

**通知類型：**

- `.settingsDidChange` - 任何設定變更時發送
- `.measurementUnitDidChange` - 測量單位變更時發送
- `.referenceObjectDidChange` - 參考物件變更時發送

**使用範例：**

```swift
// 註冊監聽
NotificationCenter.default.addObserver(
    self,
    selector: #selector(handleSettingsChange),
    name: .settingsDidChange,
    object: nil
)

// 處理變更
@objc private func handleSettingsChange() {
    applySettings()
}
```

### 自動同步

`SettingsManager` 在每次設定變更時會自動：

1. 更新 UserDefaults
2. 呼叫 `synchronize()` 確保資料持久化
3. 發送相應的通知

## 重置功能

### 1. 重置所有設定

```swift
settingsManager.resetToDefaults()
```

將所有設定恢復為預設值。

### 2. 重置測量設定

```swift
settingsManager.resetMeasurementSettings()
```

僅重置測量相關設定（單位和參考物件）。

### 3. 重置 UI 設定

```swift
settingsManager.resetUISettings()
```

僅重置使用者介面相關設定（引導、信心度指標、觸覺回饋）。

## 設定頁面整合

### SettingsViewController

**功能：**

- 載入和顯示當前設定
- 追蹤未儲存的變更
- 提供儲存和重置選項
- 監聽外部設定變更

**使用者操作流程：**

1. 使用者修改設定 → 標記為有未儲存變更
2. 點擊「儲存」→ 透過 SettingsManager 儲存設定
3. 點擊「重置」→ 顯示重置選項對話框
4. 點擊「關閉」→ 檢查是否有未儲存變更

### 主畫面整合

`ViewController` 整合設定系統：

- 在 `viewDidLoad` 中設定通知監聽
- 在 `viewWillAppear` 中套用當前設定
- 響應設定變更通知並更新 UI

## 匯入/匯出功能

### 匯出設定

```swift
let settings = settingsManager.exportSettings()
// 返回 [String: Any] 字典
```

### 匯入設定

```swift
settingsManager.importSettings(settings)
// 從字典恢復設定
```

**用途：**

- 備份使用者設定
- 在不同裝置間同步設定
- 測試和除錯

## 預設值註冊

系統在 `SettingsManager` 初始化時自動註冊預設值：

```swift
private func registerDefaultValues() {
    let defaultValues: [String: Any] = [
        UserDefaults.Keys.measurementUnit: UserDefaults.MeasurementUnit.centimeters.rawValue,
        UserDefaults.Keys.defaultReferenceIndex: 0,
        UserDefaults.Keys.showGuidance: true,
        UserDefaults.Keys.autoSave: false,
        // ... 其他預設值
    ]

    defaults.register(defaults: defaultValues)
}
```

這確保了即使使用者從未修改過設定，系統也能正確運作。

## 最佳實踐

### 1. 使用 SettingsManager

始終透過 `SettingsManager.shared` 存取設定，而非直接使用 UserDefaults。

### 2. 監聽通知

需要響應設定變更的 ViewController 應該註冊通知監聽。

### 3. 清理資源

在 `deinit` 中移除通知監聽器：

```swift
deinit {
    NotificationCenter.default.removeObserver(self)
}
```

### 4. 類型安全

使用定義好的列舉和屬性，避免使用字串鍵值。
