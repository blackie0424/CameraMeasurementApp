# 相機測量應用程式 - 權限設定說明

## 概述

相機測量應用程式需要以下權限才能正常運作。所有權限說明都已在 Info.plist 中正確設定。

---

## 必要權限清單

### 1. 相機權限 (NSCameraUsageDescription)

**權限鍵**: `NSCameraUsageDescription`

**說明文字**:

```
此應用程式需要使用相機來進行擴增實境物體測量。
```

**用途**:

- 啟動 AR 相機預覽
- 拍攝物體照片
- 進行即時物體檢測

**請求時機**:

- 應用程式首次啟動時
- 在 `ViewController.viewDidLoad()` 中檢查權限

**使用者體驗**:

```
┌─────────────────────────────────┐
│  "相機測量" 想要取用您的相機    │
│                                 │
│  此應用程式需要使用相機來進行   │
│  擴增實境物體測量。             │
│                                 │
│     [不允許]      [好]          │
└─────────────────────────────────┘
```

### 2. 相簿新增權限 (NSPhotoLibraryAddUsageDescription)

**權限鍵**: `NSPhotoLibraryAddUsageDescription`

**說明文字**:

```
此應用程式需要存取相簿來儲存測量結果的照片。
```

**用途**:

- 儲存測量結果照片到相簿
- 儲存帶有測量標註的影像

**請求時機**:

- 使用者首次點擊「儲存」按鈕時
- 在 `ResultsViewController.saveButtonTapped()` 中

**使用者體驗**:

```
│  照片圖庫                       │
│                                 │
│  此應用程式需要存取相簿來儲存   │

│                                 │
│     [不允許]      [好]          │
```

### 3. 相簿讀取權限 (NSPhotoLibraryUsageDescription)

**權限鍵**: `NSPhotoLibraryUsageDescription`

**說明文字**:

```
此應用程式需要存取相簿來儲存和分享測量結果。
```

**用途**:

- 讀取已儲存的測量照片
- 分享測量結果
- 未來功能：從相簿選擇照片進行測量

**請求時機**:

- 使用者首次使用分享功能時
- 未來：從相簿選擇照片時

**使用者體驗**:


### 4. 位置權限 (NSLocationWhenInUseUsageDescription)

**權限鍵**: `NSLocationWhenInUseUsageDescription`

**說明文字**:

```
此應用程式使用位置資訊來儲存測量的環境資訊。
```

**用途**:

- 記錄測量位置（可選）
- 在測量記錄中儲存地理位置
- 未來功能：基於位置的測量歷史

## 權限處理流程

### 相機權限處理

```swift
// ViewController.swift
private func checkPermissions() {
    let cameraStatus = AVCaptureDevice.authorizationStatus(for: .video)

    switch cameraStatus {
    case .notDetermined:
        AVCaptureDevice.requestAccess(for: .video) { [weak self] granted in
            DispatchQueue.main.async {
                if granted {
                    self?.updateStatusLabel("相機權限已授予")
                } else {
                    self?.handlePermissionDenied(.cameraPermissionDenied)
                }
            }
        }
    case .denied, .restricted:
        handlePermissionDenied(.cameraPermissionDenied)
    case .authorized:
        updateStatusLabel("相機權限已授予")
    @unknown default:
        updateStatusLabel("未知的權限狀態")
    }
}
```

### 相簿權限處理

```swift
// ResultsViewController.swift
@IBAction func saveButtonTapped(_ sender: UIButton) {
    guard let record = measurementRecord else { return }

    // 系統會自動請求權限
    UIImageWriteToSavedPhotosAlbum(
        record.image,
        self,
        #selector(image(_:didFinishSavingWithError:contextInfo:)),
        nil
    )
}

@objc private func image(_ image: UIImage,
                        didFinishSavingWithError error: Error?,
                        contextInfo: UnsafeRawPointer) {
    if let error = error {
        showError("儲存失敗: \(error.localizedDescription)")
    } else {
        showSuccess("已儲存到相簿")
    }
}
```

## 權限被拒絕的處理

### 顯示設定提示

```swift
private func showPermissionAlert(_ error: MeasurementError) {
    let alert = UIAlertController(
        title: "需要權限",
        message: error.localizedDescription,
        preferredStyle: .alert
    )

    alert.addAction(UIAlertAction(title: "前往設定", style: .default) { _ in
        if let settingsUrl = URL(string: UIApplication.openSettingsURLString) {
            UIApplication.shared.open(settingsUrl)
        }
    })

    alert.addAction(UIAlertAction(title: "取消", style: .cancel))

    present(alert, animated: true)
}
```

## 測試權限流程

### 1. 首次安裝測試

```bash
# 1. 刪除應用程式（重置權限）
# 2. 重新安裝
# 3. 啟動應用程式
# 4. 應該看到相機權限請求
# 5. 點擊「儲存」應該看到相簿權限請求
```

### 2. 權限拒絕測試

```bash
# 1. 在權限對話框中選擇「不允許」
# 2. 應該看到「前往設定」提示
# 3. 點擊「前往設定」應該開啟系統設定
# 4. 在設定中授予權限
# 5. 返回應用程式，功能應該正常
```

### 3. 模擬器測試

```bash
# 重置所有權限
xcrun simctl privacy booted reset all com.yourcompany.CameraMeasurementApp

# 授予相機權限
xcrun simctl privacy booted grant camera com.yourcompany.CameraMeasurementApp

# 授予相簿權限
xcrun simctl privacy booted grant photos com.yourcompany.CameraMeasurementApp
```

## 常見問題

### Q1: 為什麼需要兩個相簿權限？

**A**:

- `NSPhotoLibraryAddUsageDescription`: 只允許**新增**照片到相簿（iOS 11+）
- `NSPhotoLibraryUsageDescription`: 允許**讀取和新增**照片（完整存取）

我們同時設定兩個以確保在不同 iOS 版本上都能正常運作。

### Q2: 如果使用者拒絕權限怎麼辦？

**A**:
應用程式會顯示友善的提示訊息，並提供「前往設定」按鈕，引導使用者到系統設定中授予權限。

### Q3: 權限可以在應用程式內撤銷嗎？

**A**:
不行。權限只能在 iOS 系統設定中管理。應用程式只能檢測權限狀態並引導使用者到設定頁面。

### Q4: 測試時如何重置權限？

**A**:

- **實體機**: 刪除應用程式重新安裝
- **模擬器**: 使用 `xcrun simctl privacy booted reset all` 命令

### Q5: 權限說明文字可以更改嗎？

**A**:
可以，但需要注意：

- 說明必須清楚說明為什麼需要這個權限
- 說明必須是繁體中文（或使用者的語言）
- 更改後需要重新建置應用程式

## 隱私政策建議

在應用程式的隱私政策中，應該包含以下內容：

### 資料收集

```
相機測量應用程式收集以下資料：

1. 相機影像
   - 用途：進行物體測量
   - 儲存：僅在使用者選擇儲存時才會儲存到相簿
   - 不會上傳到伺服器

2. 位置資訊（可選）
   - 用途：記錄測量位置
   - 儲存：僅儲存在本地裝置
   - 不會上傳到伺服器

3. 測量資料
   - 用途：顯示和儲存測量結果
   - 儲存：僅儲存在本地裝置
   - 不會上傳到伺服器
```

### 資料使用

```
所有資料僅在本地處理，不會傳送到任何伺服器。
使用者可以隨時刪除儲存的測量記錄。
```
