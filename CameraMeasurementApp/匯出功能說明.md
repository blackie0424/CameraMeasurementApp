# 匯出功能說明

## 概述

測量資料匯出功能允許使用者將測量記錄匯出為多種格式，包括 CSV 資料檔案和標註影像。此功能已整合到結果顯示頁面和設定頁面中。

## 功能特色

### 1. CSV 資料匯出

- **格式**: 標準 CSV 格式，可用 Excel、Numbers 等軟體開啟
- **包含欄位**:

  - 記錄 ID
  - 時間戳記
  - 物體類型
  - 長度、寬度、高度（公分）
  - 體積（立方公分）
  - 測量準確度
  - 參考物件名稱
  - GPS 座標（經度、緯度）

- **使用方式**:
  - 單筆匯出：在結果頁面點擊「儲存」→「匯出為 CSV」
  - 批次匯出：在設定頁面點擊「匯出 CSV」按鈕

### 2. 標註影像匯出

- **功能**: 在原始照片上疊加測量資訊
- **標註內容**:

  - 物體邊界框（綠色線條）
  - 尺寸標註（長 × 寬 × 高）
  - 物體類型名稱
  - 參考物件視覺化（右下角）
  - 測量元資料（時間、位置等）

- **標註選項**:

  - `AnnotationOptions.default`: 標準標註（顯示所有資訊）
  - `AnnotationOptions.minimal`: 最小標註（僅顯示尺寸）
  - `AnnotationOptions.detailed`: 詳細標註（包含所有元資料）

- **使用方式**:
  - 單筆匯出：在結果頁面點擊「儲存」→「儲存標註影像到相簿」
  - 批次匯出：在設定頁面點擊「匯出影像」按鈕

### 3. 批次匯出

- **功能**: 一次匯出所有測量記錄
- **包含內容**:

  - 一個 CSV 檔案（包含所有記錄）
  - 多個標註影像檔案（每筆記錄一張）

- **檔案命名規則**:

  - CSV: `measurements_YYYYMMDD_HHMMSS.csv`
  - 影像: `measurement_YYYYMMDD_HHMMSS_N.jpg`（N 為序號）

- **使用方式**:
  - 在設定頁面點擊「匯出全部」按鈕

## 使用範例

### 範例 1: 匯出單筆測量記錄

```swift
// 在 ResultsViewController 中
guard let record = measurementRecord else { return }

// 匯出為 CSV
do {
    let csvString = try ExportManager.shared.exportRecordToCSV(record)
    let fileURL = try ExportManager.shared.saveCSVToFile(csvString)
    print("CSV 已儲存至: \(fileURL)")
} catch {
    print("匯出失敗: \(error)")
}

// 建立標註影像
do {
    let annotatedImage = try ExportManager.shared.createAnnotatedImage(from: record)
    // 儲存到相簿或檔案系統
} catch {
    print("影像標註失敗: \(error)")
}
```

### 範例 2: 批次匯出所有記錄

```swift
// 在 SettingsViewController 中
do {
    let records = try DataManager.shared.fetchAllRecords()
    let exportedURLs = try ExportManager.shared.batchExport(
        records: records,
        exportImages: true
    )
    print("已匯出 \(exportedURLs.count) 個檔案")
} catch {
    print("批次匯出失敗: \(error)")
}
```

### 範例 3: 自訂標註選項

```swift
// 建立自訂標註選項
var options = AnnotationOptions()
options.showDimensions = true
options.showObjectType = true
options.showReferenceObject = false
options.showMetadata = false
options.boundingBoxColor = .systemBlue
options.fontSize = 20.0

// 使用自訂選項建立標註影像
let annotatedImage = try ExportManager.shared.createAnnotatedImage(
    from: record,
    options: options
)
```

## 檔案儲存位置

### iOS 文件目錄

- 路徑: `Documents/`
- 可透過「檔案」App 存取
- 可透過 iTunes/Finder 檔案共享存取

### 相簿

- 標註影像可直接儲存到相簿
- 需要相簿存取權限

## 分享功能

所有匯出的檔案都可以透過 iOS 分享功能分享：

- AirDrop
- 郵件
- 訊息
- 雲端儲存（iCloud Drive、Dropbox 等）
- 其他支援的 App

## 錯誤處理

### 常見錯誤

1. **ExportError.noDataToExport**

   - 原因：沒有可匯出的測量記錄
   - 解決：先進行測量並儲存記錄

2. **ExportError.fileCreationFailed**

   - 原因：檔案建立失敗（可能是儲存空間不足）
   - 解決：檢查裝置儲存空間

3. **ExportError.imageAnnotationFailed**

   - 原因：影像標註處理失敗
   - 解決：檢查測量記錄是否包含有效的影像資料

4. **ExportError.permissionDenied**
   - 原因：沒有檔案存取權限
   - 解決：在設定中授予 App 相關權限

## 效能考量

### 批次匯出

- 使用背景佇列處理，避免阻塞 UI
- 顯示載入指示器提供使用者回饋
- 大量資料匯出時可能需要較長時間

### 影像處理

- 影像標註使用 Core Graphics 進行高效能渲染
- JPEG 壓縮品質設定為 0.9，平衡檔案大小和品質

### 記憶體管理

- 批次處理時逐筆處理記錄，避免記憶體峰值
- 完成後自動釋放暫存資料
