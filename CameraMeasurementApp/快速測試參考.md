# 第一階段快速測試參考卡

## 🎯 5 分鐘快速測試流程

### 1️⃣ 啟動應用程式

```
✓ 看到主相機畫面
✓ 頂部顯示狀態訊息
✓ 首次使用會顯示教學對話框
```

### 2️⃣ 測試拍照流程

```
點擊「拍照測量」按鈕
    ↓
等待 2 秒
    ↓
✓ 自動跳轉到測量結果頁面
✓ 顯示測試影像和測量資訊
```

### 3️⃣ 測試結果頁面功能

```
✓ 點擊「更換參考物件」→ 選擇不同的參考物件
✓ 點擊「分享」→ 看到系統分享表單
✓ 點擊「儲存」→ 儲存到相簿（需要權限）
✓ 點擊「重新拍攝」→ 返回主畫面
```

### 4️⃣ 測試設定頁面

```
點擊主畫面右上角齒輪圖示
    ↓
✓ 切換測量單位（公分/英吋）
✓ 選擇不同的參考物件（看到勾選記號）
✓ 切換開關（引導顯示、自動儲存）
✓ 點擊「儲存」→ 看到確認對話框
```

### 5️⃣ 驗證設定持久化

```
儲存設定 → 關閉應用程式 → 重新開啟 → 進入設定
    ↓
✓ 確認設定已保留
```

## 🐛 常見問題

**Q: 相機預覽是黑色/灰色的？**
A: 正常！AR 功能將在第五階段實作。

**Q: 每次拍照都是相同的影像？**
A: 正常！目前使用模擬資料測試 UI。

**Q: 測量數值不會改變？**
A: 正常！真實測量將在第七階段實作。

**Q: 無法儲存到相簿？**
A: 檢查是否授予相簿權限。

**Q: 設定沒有儲存？**
A: 確認點擊了「儲存」按鈕而非「關閉」。
