## 📱 測試步驟

### 準備工作

1. **在 Xcode 中開啟專案**

   ```bash
   open CameraMeasurementApp.xcodeproj
   ```

2. **選擇目標裝置**

   - 模擬器：選擇任何 iPhone 模擬器（建議 iPhone 15）
   - 實體機：連接您的 iPhone 並選擇為目標裝置

3. **執行應用程式**
   - 點擊 Xcode 的執行按鈕（⌘R）
   - 或使用選單：Product → Run
