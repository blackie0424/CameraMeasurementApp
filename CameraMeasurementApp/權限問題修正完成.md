# ✅ 相簿權限問題已修正

## 問題描述

在測試儲存功能時，應用程式崩潰並顯示以下錯誤：

```
[access] This app has crashed because it attempted to access privacy-sensitive
data without a usage description. The app's Info.plist must contain an
NSPhotoLibraryAddUsageDescription key with a string value explaining to the
user how the app uses this data.
```

## 問題原因

Info.plist 中缺少相簿存取權限的說明文字。iOS 要求所有存取隱私敏感資料的應用程式都必須在 Info.plist 中提供清楚的說明。

## 修正內容

已在 Info.plist 中添加以下兩個權限說明：

### 1. NSPhotoLibraryAddUsageDescription

```xml
<key>NSPhotoLibraryAddUsageDescription</key>
<string>此應用程式需要存取相簿來儲存測量結果的照片。</string>
```

**用途**: 允許應用程式將照片儲存到相簿

### 2. NSPhotoLibraryUsageDescription

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>此應用程式需要存取相簿來儲存和分享測量結果。</string>
```

**用途**: 允許應用程式讀取和新增照片（完整存取）

## 現在的完整權限清單

應用程式現在包含以下所有必要權限：

1. ✅ **相機權限** (`NSCameraUsageDescription`)

   - 用於 AR 相機和拍照功能

2. ✅ **相簿新增權限** (`NSPhotoLibraryAddUsageDescription`)

   - 用於儲存測量結果照片

3. ✅ **相簿讀取權限** (`NSPhotoLibraryUsageDescription`)

   - 用於分享和管理測量結果

4. ✅ **位置權限** (`NSLocationWhenInUseUsageDescription`)
   - 用於記錄測量位置（未來功能）

## 測試步驟

### 重新測試儲存功能

1. **刪除並重新安裝應用程式**（重置權限）

   ```bash
   # 在模擬器上
   xcrun simctl uninstall booted com.yourcompany.CameraMeasurementApp

   # 然後在 Xcode 中重新執行
   ```

2. **啟動應用程式**

   - 應該看到相機權限請求
   - 點擊「好」授予權限

3. **拍照測量**

   - 點擊「拍照測量」按鈕
   - 等待 2 秒跳轉到結果頁面

4. **測試儲存功能**

   - 點擊「儲存」按鈕
   - **首次點擊**：應該看到相簿權限請求對話框
   - 點擊「好」授予權限
   - 應該看到「已儲存到相簿」確認訊息

5. **驗證儲存**
   - 開啟相簿應用程式
   - 應該能看到剛才儲存的測量結果照片

## 如果權限被拒絕

如果使用者點擊「不允許」，應用程式會顯示友善的提示：

```
┌─────────────────────────────────┐
│  需要權限                       │
│                                 │
│  此應用程式需要相簿權限才能儲存 │
│  測量結果。請在設定中允許存取。 │
│                                 │
│     [取消]    [前往設定]        │
└─────────────────────────────────┘
```

點擊「前往設定」會開啟系統設定，使用者可以在那裡授予權限。

### 重置權限的方法

**模擬器**:

```bash
# 重置所有權限
xcrun simctl privacy booted reset all com.yourcompany.CameraMeasurementApp

# 或重置特定權限
xcrun simctl privacy booted reset photos com.yourcompany.CameraMeasurementApp
```

**實體機**:

- 刪除應用程式重新安裝
- 或在「設定 > 隱私權 > 照片」中移除權限
