# 建議的執行順序

本文件提供 AR 平面偵測與測量準確性改進功能的建議實作順序。

## 執行策略

採用**由下而上**的實作策略：先建立穩固的基礎（資料模型、核心邏輯），再逐步向上構建（UI、整合），最後進行測試和優化。

---

## 階段 1：基礎架構（關鍵核心）

**目標：建立穩定的資料模型和核心計算邏輯**

### 1.1 資料模型與基礎架構

```
任務 1: 建立平面偵測基礎架構
```

**為什麼先做：** 所有後續功能都依賴這些資料結構。`AnchoredMeasurementPoint` 是解決飄移問題的核心。

**預期成果：**

- ✅ `AnchoredMeasurementPoint` 結構完成
- ✅ `worldPosition()` 方法可以正確計算世界座標
- ✅ 基礎目錄結構建立

**總計：約 12-17 小時**

---

## 注意事項

1. **不要跳過測試**：每個階段的 property tests 都很重要，它們會幫助你發現邊界情況的 bug

2. **先解決核心問題**：階段 3-4 是解決飄移和準確性問題的關鍵，確保這部分正確實作

3. **增量測試**：完成每個任務後立即運行對應的測試，不要等到最後

4. **使用 Checkpoint**：在 Checkpoint 時確保所有測試通過再繼續

5. **真實設備測試**：AR 功能必須在真實設備上測試，模擬器無法測試 ARKit

6. **保持專注**：一次只執行一個任務，確保完成後再進行下一個
